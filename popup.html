Security
Tab-scoped sessions: Unlocking a site only allows access for that specific browser tab. Closing the tab or opening the URL in a new tab will require the password again.

Action protection: Deleting or toggling URLs requires your master password.

Extension protection: To prevent removal, pin this extension and enable Chrome's supervised user profile or use enterprise policy. Chrome does not expose an API for extensions to block their own removal — this is a browser-level control.
